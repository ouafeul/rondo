## Confirmations

| Prompt | When |
|---|---|
| `The plan for <x> DESTROYS <resources>. Apply? (y/N)` | a tofu plan deletes or replaces a resource |
| `Confirm destroying the management cluster` | `rondo destroy` |
| `Confirm destroying <targets>` | `rondo destroy downstreams` |
| `Uninstall <name> from all its Targets` | `rondo component uninstall` |

Only `y` accepts; `--yes` and `--dry-run` skip them all.

## Simulation mode

`--dry-run` logs each mutating command (`DRY-RUN <cmd>`) without running it; `kubectl get` reads do run (5 s at most). No tofu plan is computed, no token issued, no state file written.

<Aside type="caution">`rondo component install --dry-run` still downloads the component's archive; only the apply is simulated.</Aside>

## Environment variables

| Variable | Effect |
|---|---|
| `RONDO_HOME` | replaces `~/.rondo` |
| `RONDO_CRDS_DIR` | default CRDs of `rondo component lint` |
| `FORCE_COLOR` | colours even outside a terminal |
