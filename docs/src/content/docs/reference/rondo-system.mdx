  <TabItem label="ConfigMaps">

  <TabItem label="Workloads">
    | Deployment | Image | Resources (request → limit) | Probes |
    |---|---|---|---|
    | `rondo-controller` | `rondo-controller:<CLI version>` | 50m/192Mi → 500m/1Gi | `/healthz`, `/readyz` :8081 |
    | `rondo-probe` | `rondo-toolbox:<CLI version>` (`probe`) | 25m/64Mi → 200m/256Mi | |
    | `rondo-dashboard` | `rondo-toolbox:<CLI version>` (`dashboard`) | 10m/32Mi → 200m/128Mi | `/healthz` :8080 |

    1 replica each, uid/gid 65532, read-only root. The controller does leader election (Lease `rondo-controller`) and caches nothing but `rondo-system`. Service `rondo-dashboard` :80 → 8080, Ingress `rondo.<base>` (Traefik, TLS by `cluster-ca-issuer`).
  </TabItem>
  <TabItem label="Permissions">
    | Account | Scope | Permissions |
    |---|---|---|
    | `rondo-controller` | `rondo-system` | Targets, Components (read); Enrollments and statuses; Jobs (create, delete); Leases; Secrets and ConfigMaps (read); Events |
    | `rondo-exec` (Jobs) | cluster | `cluster-admin` |
    | `rondo-probe` | `rondo-system` + cluster | RONDO objects (read), `enrollments/status` (patch), Secrets (read); `view` + read on RBAC, CRDs, StorageClasses, webhooks… |
    | `rondo-dashboard` | `rondo-system` | RONDO objects, Jobs, Deployments, Pods and logs (read); no Secret |

    On a remote target, Jobs and the probe have the permissions of the identity in the Target's kubeconfig.
  </TabItem>
  <TabItem label="Network">
    | NetworkPolicy | Effect |
    |---|---|
    | `rondo-default-deny-ingress` | no `rondo-system` pod accepts incoming connections… |
    | `rondo-dashboard-from-ingress` | …except the dashboard, from `kube-system` (Traefik), on its `http` port |

    No egress rule.
  </TabItem>

## Leases

| Name | Role |
|---|---|
| `rondo-controller` | election of the active controller |
| `rondo-lock-enrollment-<name>` | one Job at a time per Enrollment |

## Outside rondo-system

| Object | Where | Role |
|---|---|---|
| `tls-ca` | `cattle-system` | Rancher's CA |
| `regcred` | `fleet-default` | registry of the rke2 nodes |
| ClusterIssuers `selfsigned-bootstrap`, `cluster-ca-issuer` | cluster | internal PKI, CA `RONDO <env> CA` |
| IPAddressPool `default-pool`, L2Advertisement `default-l2` | `metallb-system` | management ingress IP |
