## Cross-key rules

| Rule | Message |
|---|---|
| names unique across `targets.vsphere` and `targets.downstreams` | `targets: duplicate name "<n>"` |
| name and role `management` reserved | `the name and role "management" are reserved for the management cluster` |
| each `vsphereTarget` names an entry of `targets.vsphere` | `vsphereTarget "<ref>" names no vsphere target` |
| one vCenter password per vSphere Target, no other | `secrets.vcenterPasswords.<n> is required` / `no vsphere target has this name` |
| odd number of rke2 control planes | `must hold an odd number of nodes (etcd quorum)` |
| exactly 3 `serverNodes` | |
| `preset: generic` declares `oci.registry`, `files.url` | `artifacts.<key> is required with artifacts.preset: generic` |
| `preset: generic` declares one of `tofu.providerMirror`, `tofu.providerOCI` | `… is required with artifacts.preset: generic` / `… are exclusive` |
| `tofu.providerOCI` is `<registry>/<repository>`, and comes without `secrets.mirrorToken` | `artifacts.tofu.providerOCI (…) must be <registry>/<repository>, without a scheme` |
| `preset: generic` declares one of `tofu.state.http`, `tofu.state.s3` | `artifacts.tofu.state.http or artifacts.tofu.state.s3 is required…` / `… are exclusive` |
| `tofu.state.s3` has credentials: `secrets.mirrorStateAccessKey` and `mirrorStateSecretKey` (together), else `artifacts.username` | `artifacts.tofu.state.s3 needs credentials…` |
| `artifacts.username` and `secrets.mirrorPassword` both set, or both empty (anonymous mirror) | `artifacts.username and secrets.mirrorPassword go together…` |
| `oci.registry` is `host[:port]` | `artifacts.oci.registry (…) must be host[:port], without a scheme or a path` |
| `rpm.url` is empty or `files.url` | `artifacts.rpm.url (…) must be artifacts.files.url (…) or empty` |
| `preset: artifactory` declares `artifactory.url` and nothing under `oci`, `files`, `rpm` | `artifacts.artifactory.url is required…` / `artifacts.<key> is not read with artifacts.preset: artifactory` |
| `preset: artifactory` has no `artifactory.repositories.tofu`: the providers come from `<url>/<generic>/providers/`, or from `tofu.providerMirror` | `artifacts.artifactory.repositories.tofu (…) is not read…` |
| `preset: artifactory` takes `tofu.state` or `artifactory.repositories.tofuState`, not both | `artifacts.tofu.state and artifacts.artifactory.repositories.tofuState are exclusive…` |
| `preset: generic` has no `artifactory` block | `artifacts.artifactory is only read with artifacts.preset: artifactory` |

## Artifact mirror presets

Every repository is a path segment under its root, `<root>/<repository>/<path>`, as in the
`repo` fields of the Components.

| Endpoint | `preset: generic` | `preset: artifactory` |
|---|---|---|
| images | `<oci.registry>/<oci.repository>/<image>` | `<host>/<docker>/<image>` |
| Helm charts | `oci://<oci.registry>/<oci.chartsRepository>/<chart>` | `oci://<host>/<helm>/<chart>` |
| RONDO files | `<files.url>/<files.repository>/…` | `<url>/<generic>/…` |
| RPM repositories | `<rpm.url>/<rpm.repository>/…` | `<url>/<rpm>/…` |
| tofu providers | `<tofu.providerMirror>` (network mirror), or `<tofu.providerOCI>/<namespace>/<type>` (OCI mirror) | `<url>/<generic>/providers/` (the static network mirror tree `download-deps.py` uploads), or `tofu.providerMirror` / `tofu.providerOCI` when set |
| tofu states | `<tofu.state.http.url>/<environmentName>/…`, or `s3://<bucket>/<keyPrefix>/<environmentName>/…` | `<url>/<tofuState>/<environmentName>/…`, or `tofu.state` when set |
| rke2 system registry | `<oci.registry>`, image paths rewritten under `<oci.repository>` | `<docker>.<host>` |
| public images on the nodes (`docker.io`, `registry.k8s.io`, `quay.io`, `ghcr.io`, `gcr.io`) | pulled as `<oci.registry>/<oci.repository>/<path>` | from their own registry |
| provider mirror token | `secrets.mirrorToken`, else none | `secrets.mirrorToken` (used as is, never revoked), else issued on each deploy through the JFrog Access API |
| credentials, CA | optional: anonymous, system trust store | as declared |

`<host>` is the host of `artifactory.url`; `<docker>`, `<helm>`… are `artifactory.repositories.*`.

With `preset: artifactory`, `artifacts.tofu` is optional and overrides what it sets: a provider
mirror elsewhere (`providerMirror`, or `providerOCI`), a state backend elsewhere (`state.http` or
`state.s3`, in place of `repositories.tofuState`). An Artifactory Terraform repository serves the
network mirror protocol under its API; to install the providers from one instead of the static
tree, name it:

```yaml
artifacts:
  preset: artifactory
  artifactory:
    url: https://artifactory.example.local/artifactory
  tofu:
    providerMirror: https://artifactory.example.local/artifactory/api/terraform/<repository>/providers/
```

### Provider mirror token

The `.tofurc` of the CLI and of the Jobs presents a Bearer token to a network mirror
(`credentials "<host>"`). It is `secrets.mirrorToken` when set, whatever the preset: RONDO uses it
as is and neither mints nor revokes it. Otherwise, with `preset: artifactory` and a network mirror,
`rondo deploy` mints the tokens with `artifacts.username` and `secrets.mirrorPassword` through the
JFrog Access API, at the platform root (`artifactory.url` without its `/artifactory` context):

| Token | Request | Lifetime |
|---|---|---|
| the CLI's, for each deploy | `POST <platform>/access/api/v1/tokens`, `scope=applied-permissions/user` | 1 hour |
| the Jobs', kept in the `rondo-tofurc` Secret | the same | `artifactory.mirrorTokenLifetimeSeconds`; empty: no expiry, which only an admin account gets |

The next deploy mints a new Jobs' token and revokes the previous one with
`DELETE <platform>/access/api/v1/tokens/me`, authenticated by that token. Minting with basic
credentials needs an internal user without multi-factor authentication, on a platform that allows
token creation with basic credentials; when the Access API refuses, `rondo deploy` stops and says
so: create a token that reads the provider mirror (JFrog Platform UI, `jf access-token-create`) and
set it in `secrets.mirrorToken`.

### OpenTofu providers in an OCI registry

With `tofu.providerOCI: registry.example.local/opentofu-providers`, the `.tofurc` of the CLI and
of the Jobs reads:

```hcl
provider_installation {
  oci_mirror {
    repository_template = "registry.example.local/opentofu-providers/${namespace}/${type}"
    include             = ["registry.opentofu.org/*/*"]
  }
}
oci_credentials "registry.example.local" {
  username = "<artifacts.username>"
  password = "<secrets.mirrorPassword>"
}
```

Each provider is one repository, one tag per version, an index of `linux/amd64` artefacts as
OpenTofu's [provider mirror in OCI registries](https://opentofu.org/docs/cli/oci_registries/provider-mirror/)
describes; `oras` pushes them. `oci_credentials` is left out for an anonymous mirror.

### State in S3

```yaml
artifacts:
  tofu:
    state:
      s3:
        bucket: rondo-states
        endpoint: https://minio.example.local:9000
        region: us-east-1      # default
        keyPrefix: sites       # optional
        usePathStyle: true     # MinIO, most on-premises stores
secrets:
  mirrorStateAccessKey: …     # optional: artifacts.username and mirrorPassword otherwise
  mirrorStateSecretKey: …
```

The modules declare `backend "http" {}`; with `s3` RONDO writes a `backend_override.tf` that
selects `backend "s3" {}` and configures it at `tofu init` (bucket, key, endpoint, a lock file
next to the state with `use_lockfile`, no AWS account or STS check). The keys reach OpenTofu as
`AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`, on the CLI and through the Secret
`rondo-credentials` in the machine Jobs.

## What the CLI derives from it

| Derived | Value |
|---|---|
| hosts | `rancher.<ingressBaseDomain>`, `rondo.<ingressBaseDomain>` |
| tofu states | `<state base>/<environmentName>/{k3s, <target>, vm/<enrollment>}/terraform.tfstate` |
| vSphere folders | `<vmFolder>/<env>/MANAGEMENT`, `<vmFolder>/<env>/<rke2 target>`, `<vmFolder>/<env>/<component>` |
| registry (management) | the images prefix of the mirror, e.g. `<oci.registry>/<oci.repository>` |
| registry (rke2) | `rke2.registryHost`, else the rke2 system registry of the mirror |
| internal CA | `RONDO <environmentName> CA` |

<Aside type="tip">After a change: `rondo deploy` for the management cluster, the vSphere Targets, the secrets and the DNS; `rondo deploy downstreams <t>` for an rke2 cluster and its Target.</Aside>
