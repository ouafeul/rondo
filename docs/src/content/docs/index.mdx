## The essentials

<Tabs>
  <TabItem label="Install a site">
    ```bash
    sudo dnf install -y rondo
    rondo init                         # writes ~/.rondo/rondo.yaml, to fill in
    rondo deploy                       # k3s management, Rancher, operator, Targets
    rondo deploy downstreams           # one rke2 cluster per target, and its base layer
    rondo component install acme       # a component, on the targets of its roles
    ```
  </TabItem>
  <TabItem label="Monitor">
    ```bash
    kubectl -n rondo-system get targets,enrollments
    kubectl -n rondo-system describe enrollment grafana
    kubectl -n rondo-system logs job/<job>
    # or https://rondo.<ingressBaseDomain>, read-only
    ```
  </TabItem>
  <TabItem label="Remove">
    ```bash
    rondo component uninstall acme
    rondo destroy downstreams
    rondo destroy
    ```
  </TabItem>
</Tabs>
