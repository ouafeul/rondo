One workstation drives several sites, one **environment** each: its `rondo.yaml`, its local state, its tofu states, its vSphere folder, its kubectl context.

```bash
rondo init --env staging      # writes ~/.rondo/envs/staging/rondo.yaml (environmentName: staging)
rondo env list                # * marks the selected environment; default is always listed
rondo env select staging      # following commands + kubectl context rondo-staging
rondo deploy --env prod       # once, without changing the selection
rondo env select default      # back to ~/.rondo/rondo.yaml
```

| Per environment | Value |
|---|---|
| tofu states | `<state base>/<environmentName>/…` |
| vSphere folder | `<vmFolder>/<environmentName>/…` |
| kubectl context | `rondo` (default) or `rondo-<env>` |
| cluster CA | `RONDO <env> CA` |

## Which rondo.yaml?

In order: `--config`; else `--env` (or the selected environment) → `$RONDO_HOME/envs/<env>/rondo.yaml`; else `./rondo.yaml`; else `$RONDO_HOME/rondo.yaml`. If the file's `environmentName` does not match the targeted environment, the command stops.

`artifacts.caCertificateFile` accepts `~`; a relative path starts from the folder of `rondo.yaml`.

## Bundle and channel

Outside a clone of the repository, the CLI downloads its **IaC bundle** (tofu modules, `helmfile.yaml.gotmpl`, CRDs, platform tree, scripts) from the site's artifact mirror into `~/.rondo/cache/<version>`, checked by SHA-256:

| Priority | Source of the version |
|---|---|
| 1 | `--iac-version` |
| 2 | `--iac-channel` |
| 3 | `artifacts.releaseChannel` |
| 4 | `edge-<branch>` for an edge CLI |
| 5 | `stable` |

Run from a clone (where `manifests/dependencies.yaml` exists), the CLI uses the clone's files.
